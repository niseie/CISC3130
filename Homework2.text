2.  The bigger the array the worse the time complexity gets on scale. This is because it needs to iterate
through both the of the loops, and this takes way more time to complete through one full iteration. In the time that 
it takes to compare one index to the other over and over again, if there is a very long array of 1000+ indices, then 
it can get out of hand with the amount of time it'll take.
3.  Every single time you increase the number of of elements, the number of comparisons increase by a square of that factor. In this

Part 11
7.  Linear search is the time complexity O(n). 
8.  Binary search is the time complexity O(log n)
9.  Binary search requires the elements to be sorted because it looks for the middle element and compares
the target value to the middle element.
10. If the data set is not sorted you could use the Linear search since it doesn't require comparison 
and instead searches for the target by searching through each element. 
11. The binary search is better for a very large sorted array because it cuts the array in half and then compares the middle element 
to the target and if the middle element is less or greater than the target, it discards the other half 
and continues this same process until it's done and has found the target. 
12. 
Algoritm            Purpose         Big O
Bubble Sort         Sorting         O(n^2)
Merge Sort          Sorting         O(n log n)
Linear Search       Searching       O(n)
Binary Search       Searching       O(log n)
